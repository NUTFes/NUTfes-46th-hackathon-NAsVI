## やること
- [ ] `Cf-Access-Jwt-Assertion` ヘッダーを優先し、無いときだけ `Sec-Fetch-Site: same-origin` の場合に `CF_Authorization` Cookie から JWT を読む。不正ヘッダーではフォールバックせず、Cookie 欠落も 401。両経路で共通の署名検証(JWKS の取得とキャッシュ、iss・aud・exp の確認)と email claim の必須・非空検証を行い、失敗は 401
- [ ] 検証できたら `c.set('actor', {email})`。できなければ 401 problem+json
- [ ] `ACCESS_BYPASS=true` のときだけ検証を迂回する(開発・テスト用)。本番の設定で迂回が有効にならないことを README に書く

## 受け入れ条件(それぞれテストで確かめる)
- [ ] テスト: 正しい JWT・期限切れ・署名不正・aud 不一致・email 欠落/空・ヘッダー優先・不正ヘッダー時のフォールバック拒否・same-origin の Cookie 認証・Sec-Fetch-Site 不一致/欠落と Cookie 欠落の拒否・迂回
- [ ] テストは、テスト内で作った鍵ペアと偽の JWKS で行う(外部通信なし)

## 注意
Cloudflare 側の設定(ポリシー、AUD、チームのドメイン)は人が行う(D-03)。値は環境変数で受ける。
