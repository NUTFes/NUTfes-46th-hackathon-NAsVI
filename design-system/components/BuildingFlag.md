# BuildingFlag

- status: proposed
- 目的(1 文): 企画のある建物と企画数を地図に示し、押すと建物の中の地図を開く
- 使う画面: map
- 見せる概念・項目: landmarks(建物の位置)と、その建物の places の数

## 構造(anatomy)
1. 旗のアイコン
2. 企画数

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| landmarkId | 文字列 | ○ | — | 建物の id。API の項目名と同じ名前にする(D-020、#21 の API-39) | landmarks.id(場所の landmarkId と同じ値) |
| count | 数 | ○ | — | 絞り込み中は絞った後の数 | なし(端末で places の building から数える。D-017。設備は数えない。D-030) |
| selected・isDestination | 真偽 |  | false |  | なし |
| onPress | 関数 | ○ | — |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | mint の札 | event、event-on、map-ring |
| 選択中 | 白い縁 | map-ring |
| 行き先 | 黄 | destination、destination-on |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 企画が 1 件以上ある建物
- 使わない: 屋外の企画は EventMark

## アクセシビリティ
- 操作方法: タップ
- 読み上げの文言: 「図書館棟・企画 2 件」
- 押せる大きさ: 札の周りを 44 px 押せるようにする
- 色だけに頼っていないか: 旗の形と数字

## 未確認・要確認
- 解消(D-017): 場所が建物(building)と階(floor)を持つ
