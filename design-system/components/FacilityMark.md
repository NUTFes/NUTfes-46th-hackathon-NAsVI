# FacilityMark

- status: proposed(※ の決定待ち。決まるまで仕様を確定にしない)
- 目的(1 文): 設備(案内所・トイレ・休憩所・ゴミ箱)の位置を示す
- 使う画面: map、building
- 見せる概念・項目: places(kind=facility ※)

## 構造(anatomy)
1. 白い丸
2. 種類のアイコン(トイレは塗りつぶしの男女、案内所は丸で囲んだ i)

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| kind | 列挙 | ○ | — | info / wc / rest / trash | places.kind ※ |
| zoomed | 真偽 |  | false |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 白い丸と濃いアイコン | facility、facility-on、map-ring |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 設備
- 使わない: —

## アクセシビリティ
- 操作方法: なし(押すかは未定)
- 読み上げの文言: 「トイレ」
- 押せる大きさ: —
- 色だけに頼っていないか: アイコンの形で区別し、色は増やさない
