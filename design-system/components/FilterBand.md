# FilterBand

- status: proposed
- 目的(1 文): いま絞り込み中であることと件数を示し、解除できるようにする
- 使う画面: map(V1-m)、search(V1-b・c)、list(V2)
- 見せる概念・項目: Labeling.filtering(端末)、件数(端末で数える)

## 構造(anatomy)
1. 漏斗のアイコン
2. 文: 「『〇〇』で絞り込み中・N 件」
3. 解除

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| labels | 文字列の配列 | ○ | — | 選んでいる種類・タグ | なし(端末) |
| count | 数 | | なし | 絞った後の件数。検索中は出さない | なし |
| emptyHint | 文字列 | | なし | 0 件のときの理由と次の手(タグごとに文を用意する) | なし |
| onClear | 関数 | ○ | — | clearFilter | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | | bg-surface、border-subtle、text-primary |
| 押下 | なし(押せるのは解除だけ) | |
| 無効 | なし | |
| 読み込み中 | なし | |
| 空(0 件) | 文を 2 行にし、0 件の理由と次の手を出す。例: 「『お気に入り』で絞り込み中・0 件」+「お気に入りはまだありません。場所のカードの ☆ で付けられます」。地図(V1-o)でも同じ(apply-log ⑧、2026-11-22 に決定) | text-primary、text-secondary |
| エラー | なし | |

## 使う / 使わない
- 使う: 絞り込みが効いている画面すべて(同じ見せ方にそろえる。机上の点検 ①)
- 使わない: 絞り込みをしていないときは出さない

## アクセシビリティ
- 読み上げの文言: role="status"。変わったら読み上げる
- 押せる大きさ: 解除は 44 px
- 色だけに頼っていないか: 文で示す

## 未確認・要確認
