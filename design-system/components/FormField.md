# FormField

- status: proposed
- 目的(1 文): 運営が、名前・説明・選択を入れる
- 使う画面: op_places、op_landmarks
- 見せる概念・項目: places / landmarks の各項目

## 構造(anatomy)
1. ラベル
2. 入力(1 行・複数行・選択)。複数を選ぶ欄(場所に付ける運営の種類。O1)は、`kind` を使わず、ラベルの下に CheckRow を並べる
3. 補足・エラー

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| label | 文字列 | ○ | — |  | なし |
| kind | 列挙 | ○ | text | text / textarea / select | なし |
| value | 文字列 | ○ | — |  | 各項目 |
| error | 文字列 |  | なし |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | bg-page、border-subtle |
| エラー | 赤い枠と文 | danger、danger-text |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 運営の画面
- 使わない: 場所の更新では、種別(kind)の欄を出さない。登録後に種別は変えられない(変えるときは削除して登録し直す。D-031)。種別は DataTable の「種別」列で見られる。この部品の `kind`(text・textarea・select)は入力欄の種類で、場所の種別とは別

## アクセシビリティ
- 操作方法: キーボード
- 読み上げの文言: ラベルと結び付ける
- 押せる大きさ: 高さ 40 px(PC)
- 色だけに頼っていないか: エラーは文で
