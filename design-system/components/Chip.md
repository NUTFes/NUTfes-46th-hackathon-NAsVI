# Chip

- status: proposed
- 目的(1 文): 種類や自分用のタグで、場所を絞り込む
- 使う画面: map、search、list(V1-a・b・c・d・e・g・i・m、V2)
- 見せる概念・項目: Labeling(種類は places の「種類」、タグは端末の中のデータ。D-014)

## 構造(anatomy)
1. 面: 丸い枠
2. チェック(選択中だけ)
3. 文字: 種類名かタグ名
4. 列: Chip を横に並べ、横にスクロールする。種類とタグの間に区切り線

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| label | 文字列 | ○ | — | 「飲食」「行きたい場所」など | places の種類の名前(種類)/ なし(タグは端末) |
| selected | 真偽 | ○ | false | 絞り込みに使っているか | なし(端末の状態。Labeling.filtering) |
| source | 列挙 | ○ | — | kind(運営の種類)/ tag(自分用のタグ) | なし |
| onToggle | 関数 | ○ | — | applyFilter・clearFilter | なし(端末の中) |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 枠だけ | bg-surface、border-subtle、text-secondary |
| 押下 | 面を少し明るく | (未定) |
| 無効 | なし(どのチップもいつでも押せる) | |
| 読み込み中 | なし | |
| 空 | なし(種類が 0 なら列ごと出さない) | |
| エラー | なし | |
| 選択中 | 面を lilac、チェックを出す | action-primary、action-on-primary |

## 使う / 使わない
- 使う: 場所の一覧と地図を絞るとき。選ぶと FilterBand も出す(机上の点検 ①)
- 使わない: 表示する印の入・切(V1-h)は CheckRow。絞り込みとは目的が違う

## アクセシビリティ
- 操作方法: タップ。押すたびに入・切
- 読み上げの文言: 「飲食、絞り込み、オン」(aria-pressed)
- 押せる大きさ: 高さ 32 px。列の上下に余白を取り、押せる範囲を 44 px にする
- 色だけに頼っていないか: 選択中はチェックの印も出す

## 未確認・要確認

- 複数選んだときの絞り方(どれか / すべて)。概念は「どれか」(show-places の where)
