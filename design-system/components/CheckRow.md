# CheckRow

- status: proposed
- 目的(1 文): 1 つの項目の入・切を選ぶ
- 使う画面: layers(V1-h)、tags(V1-l)
- 見せる概念・項目: 表示する印(端末の設定)、タグ(端末。D-014)

## 構造(anatomy)
1. アイコン
2. 名前と補足
3. チェック

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | text-primary、text-secondary |
| 選択中 | チェックの面を lilac | action-primary、action-on-primary |
| 押下 |  | state-pressed |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: いくつかの項目を、それぞれ入・切するとき
- 使わない: 1 つを選ぶだけなら Chip

## アクセシビリティ
- 操作方法: 行のどこを押しても切り替わる
- 読み上げの文言: role="checkbox"、aria-checked
- 押せる大きさ: 行の高さ 54 px
- 色だけに頼っていないか: チェックの印で分かる
