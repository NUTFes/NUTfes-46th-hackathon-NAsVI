# StampMark

- status: proposed
- 目的(1 文): スタンプ(混雑・感想)を地図に示す。拡大すると種類と経過時間
- 使う画面: map
- 見せる概念・項目: stamps の種類・位置・押した時刻

## 構造(anatomy)
1. 丸(混雑は濃淡と数字、感想はマーク)
2. 札(拡大時: 種類と経過時間)

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| kind | 列挙 | ○ | — | congestion-1〜5 / fun / food / good | stamps.kind |
| pressedAt | 時刻 | ○ | — | 経過時間を出す | stamps の押した時刻 |
| zoomed | 真偽 |  | false |  | なし |
| more | 数 |  | 0 | まとめたほかの件数。1 以上なら「+N」を出す | なし(端末でまとめる) |

## まとめ方(apply-log ⑩、2026-11-22 に決定)
- 画面の上で近いスタンプ(目安 24 px 以内。実機で決める)を 1 つにまとめる
- 代表は、混雑なら一番新しいもの(原則 P2)、感想なら一番多い種類。件数を「+N」で出す
- 拡大すると、離れたものはまとめを解く。拡大の札は「混雑4 6分 +5」
- 地図の見せ方だけの話で、概念設計(Stamp)と API は変わらない
