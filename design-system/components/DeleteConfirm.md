# DeleteConfirm

- status: proposed
- 目的(1 文): 運営が、消す前に連動して起きることを見て決める
- 使う画面: op_places、op_landmarks
- 見せる概念・項目: places / landmarks

## 構造(anatomy)
1. 見出し(何を消すか)
2. 連動して起きること
3. 削除する・やめる

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| title | 文字列 | ○ | — |  | なし |
| effects | 文字列 | ○ | — | 「検索・一覧から消え、案内も終わる」 | なし |
| onConfirm・onCancel | 関数 | ○ | — | removePlace / removeLandmark | DELETE |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 赤い枠 | danger、danger-bg |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 削除の前(戻せない操作)
- 使わない: —

## アクセシビリティ
- 操作方法: キーボード。最初のフォーカスは「やめる」
- 読み上げの文言: role="alertdialog"
- 押せる大きさ: 40 px
- 色だけに頼っていないか: 文で分かる
