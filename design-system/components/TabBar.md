# TabBar

- status: proposed
- 目的(1 文): 一覧・マップ・カメラを切り替える
- 使う画面: 来場者の全画面
- 見せる概念・項目: なし

## 構造(anatomy)
1. 3 つのタブ(アイコンと文字)
2. 今いるタブの印(色)

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| current | 列挙 | ○ | map | list / map / camera | なし |
| onChange | 関数 | ○ | — |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 文字は補足の色 | bg-surface、text-secondary |
| 選択中 | 文字を本文の色、アイコンを mint | text-primary、event |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 来場者の画面の一番下に、いつも出す
- 使わない: 運営の画面(PC)は上のタブ

## アクセシビリティ
- 操作方法: タップ
- 読み上げの文言: 「マップ、選択中」(aria-current)
- 押せる大きさ: 1 つのタブの高さ 72 px
- 色だけに頼っていないか: 選択中は色と、文字の太さ
