# EventMark

- status: proposed
- 目的(1 文): 屋外の企画の位置を示す。拡大すると名前を出す
- 使う画面: map
- 見せる概念・項目: places(kind=event、建物なし)の位置・名前

## 構造(anatomy)
1. 旗の丸
2. 名前(拡大時)

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| placeId | 文字列 | ○ | — |  | places.id |
| name | 文字列 | ○ | — |  | places.name |
| zoomed | 真偽 | ○ | false |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | mint の丸 | event、event-on、map-ring |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 屋外の企画
- 使わない: 建物の中の企画は BuildingFlag にまとめる

## アクセシビリティ
- 操作方法: タップでカード
- 読み上げの文言: 「屋外の企画: ステージ」
- 押せる大きさ: 周りを 44 px
- 色だけに頼っていないか: 旗の形

## 未確認・要確認
- なし
