# DataTable

- status: proposed
- 目的(1 文): 運営が、場所・建物の一覧と状態を見る
- 使う画面: op_places、op_landmarks
- 見せる概念・項目: places、landmarks

## 構造(anatomy)
1. 見出しの行
2. 行(名前・種別・種類・位置の状態・操作)

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| rows | 配列 | ○ | — |  | places / landmarks |
| selectedId | 文字列 |  | なし | 編集中の行 | なし |
| onEdit | 関数 | ○ | — |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | bg-surface、border-subtle |
| 選択中 | 行を薄い lilac | action-selected-bg |
| 空 | 「まだ登録されていません」と、新しい場所 |  |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない
- 使う: 運営の画面
- 使わない: 来場者の一覧は PlaceRow

## アクセシビリティ
- 操作方法: キーボードで行を移れる
- 読み上げの文言: 表として読む
- 押せる大きさ: 編集は 36 px(PC)
- 色だけに頼っていないか: 状態は文字の札
