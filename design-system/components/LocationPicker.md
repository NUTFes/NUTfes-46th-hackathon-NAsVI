# LocationPicker

- status: proposed
- 目的(1 文): 運営が、地図を押して場所・建物の位置を置く
- 使う画面: op_places、op_landmarks
- 見せる概念・項目: places.location、landmarks の位置

## 構造(anatomy)
1. 小さい地図
2. 印
3. 座標の表示

## props
| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| value | 位置(地図の中の割合 `{x, y}`。0〜100) |  | なし | 部品は地図の中の割合だけを受け渡す。API の位置は緯度経度(`{lat, lng}`)で、割合との変換は画面の側で行う | location(`{lat, lng}`。#21) |
| onChange | 関数 | ○ | — |  | なし |

## 状態
| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | destination(印) |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |
