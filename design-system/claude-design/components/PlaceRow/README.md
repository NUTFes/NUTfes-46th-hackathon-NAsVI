# PlaceRow

場所 1 件を一覧に並べ、押すと場所のカードを開く。

- 使う画面: search(V1-b)、list(V2)、camera(V3-a・b)、building(V1-k)
- 見せるもの: Place(places の id・名前・種類・建物・階。D-017)、距離(端末で計算)、タグの状態(端末)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

並べ方: `<div class="nv-list">` の中に並べる(行どうしの区切り線が付く)。

## 作り

1. 名前: 1 行。検索中は一致した文字を強調
2. 補足: 種類の Badge と、建物・階
3. 距離: 右寄せ(現在地があるときだけ)
4. タグの切り替え: しおり(行きたい場所)と星(お気に入り)。一覧だけ

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| placeId | 文字列 | ○ | — | 押したとき・タグを付けるときに使う。**会期中に変わらないこと**(#17) | places.id |
| name | 文字列 | ○ | — | 長い名前は 2 行まで | places.name |
| kindLabel | 文字列 | | なし | 「体験」など | places の種類 |
| building | 文字列 | | なし | 「図書館棟」「屋外」 | places の建物 |
| floor | 文字列 | | なし | 「2階」 | places.floor(数。「2階」にして渡す。D-017) |
| distanceM | 数 | | なし | 直線距離。現在地が無ければ出さない | なし(端末で計算。places.location と現在地) |
| highlight | 文字列 | | なし | 検索語。名前の中で強調 | なし |
| tags | {wantToGo, favorite} | | なし | 渡すと右にしおりと星を出す | なし(端末。D-014) |
| onOpen | 関数 | ○ | — | 場所のカードを開く | なし |
| onToggleTag | 関数 | | なし | | なし(端末) |

Design System で足した props: isDestination・loading(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 使う / 使わない

- 使う: 場所を何件か並べるとき
- 使わない: 1 件をくわしく見せるときは PlaceCard

## アクセシビリティ

- 操作方法: 行をタップでカード。しおり・星は別の押せる所
- 読み上げの文言: 「F2 ポケモンカード体験会、体験、図書館棟、130 メートル」
- 押せる大きさ: 行の高さ 56 px 以上、しおり・星は 40×44 px
- 色だけに頼っていないか: タグの入・切は塗りと形(しおり・星)で分かる
