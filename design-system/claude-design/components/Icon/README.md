# Icon

ワイヤーフレームのアイコンを、24 の格子の線で描く。

- 使う画面: すべて(部品の中で使う)
- 状態: 【Design System で追加】部品の一覧(35 個)には無い。どの部品も同じ線のアイコンを使うため、1 つにまとめた

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 説明 |
|---|---|---|---|---|
| name | アイコン名 | ○ | — | `NAsVI.Icon.names` に一覧(29 個) |
| size | 数 | | 20 | px |
| filled | 真偽 | | false | star・bookmark・navigation を塗りつぶす(選択中・行き先の矢印) |
| strokeWidth | 数 | | アイコンごと | 線の太さ。ワイヤーフレームの値が既定 |
| rotate | 数 | | 0 | 回転(度)。行き先の矢印に使う |
| label | 文字列 | | なし | 渡すと読み上げる(role="img")。渡さなければ飾り(aria-hidden) |

## 使う / 使わない

- 使う: 色は CSS の `color` を引き継ぐ(`currentColor`)。部品の文字の色と同じにする
- 使う: トイレ(wc)は塗りつぶしの男女、案内所(info)は丸で囲んだ「i」(2026-11-22 に決定)
- 使わない: 絵文字。アイコンだけで意味を伝えない(ボタンには文字か、読み上げ用の名前を付ける)
