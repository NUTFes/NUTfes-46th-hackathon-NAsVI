# BuildingFloorPlan

階の見取り図と、企画・設備の位置を示す。

- 使う画面: building(V1-j・k)
- 見せるもの: 見取り図(概念の外。D-029)、places の位置
- 状態: 下書き(チームで確認する前)

## 作り

1. 見取り図
2. 企画の印
3. 設備の印

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| plan | 画像か形 | ○ | — |  | 見取り図(概念にしない。D-029)。#21 の API は `{viewBox, d}` と、四隅の緯度経度(bounds)を返し、画面が x・y を計算する(API-29・30。#21 の台帳で確定) |
| places | 配列 | ○ | — |  | places |

Design System で足した props: label・note・onOpen(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 空 | 「この階に企画はありません」と、ほかの階への案内(EmptyState) |  |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 建物の中の地図
- 使わない: —

## アクセシビリティ

- 操作方法: なし
- 読み上げの文言: 画像の説明と、企画の一覧を別に出す
- 押せる大きさ: —
- 色だけに頼っていないか: 印の形
