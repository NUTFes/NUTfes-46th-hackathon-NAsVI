# LocationPicker

運営が、地図を押して場所・建物の位置を置く。

- 使う画面: op_places、op_landmarks
- 見せるもの: places.location、landmarks の位置
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 小さい地図
2. 印
3. 座標の表示

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| value | 位置 |  | なし |  | location |
| onChange | 関数 | ○ | — |  | なし |

Design System で足した props: buildings・label(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | destination(印) |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 運営の画面
- 使わない: —

## アクセシビリティ

- 操作方法: 押して置く。座標を文字でも入れられるようにする
- 読み上げの文言: 座標を読む
- 押せる大きさ: —
- 色だけに頼っていないか: 印の形
