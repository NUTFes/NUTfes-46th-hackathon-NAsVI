# Badge

種類・状態を小さく示す。

- 使う画面: list、card、op_places
- 見せるもの: places の種類・種別
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 文字(小さい面)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| label | 文字列 | ○ | — | 「体験」「駐車場」「設定済み」「要確認」 | places の種類・kind |
| tone | 列挙 |  | neutral | neutral / parking / ok / warn | なし |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | action-selected-bg、text-primary、parking、event、danger-text |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 一覧の行や表の中で、種類や状態を添えるとき
- 使わない: 押せる絞り込みは Chip

## アクセシビリティ

- 操作方法: なし(押せない)
- 読み上げの文言: 文字を読む
- 押せる大きさ: —
- 色だけに頼っていないか: 文字で分かる

## 未確認・要確認

- なし
