# Toast

操作の結果を短く知らせ、取り消せるようにする。

- 使う画面: stamp(V1-f)
- 見せるもの: Stamp(押した種類)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

画面の上に出す位置と、消すまでの時間(durationMs)は、使う側が決める。

## 作り

1. 札(押した種類)
2. 文
3. 取り消す

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| message | 文字列 | ○ | — | 「混雑3 を足元に押しました」 | なし |
| undoLabel | 文字列 |  | 取り消す |  | なし |
| onUndo | 関数 |  | なし | retractStamp | DELETE /stamps/{stampId}(proof をヘッダー X-Stamp-Proof で送る。D-021、#21) |
| durationMs | 数 |  | 6000 |  | なし |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 画面の上に出て、時間で消える | bg-surface、border-subtle |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: スタンプを押した直後
- 使わない: 失敗は Banner

## アクセシビリティ

- 操作方法: 取り消すをタップ
- 読み上げの文言: role="status"
- 押せる大きさ: 取り消すは 44 px
- 色だけに頼っていないか: 文で分かる

## 未確認・要確認

- 解消(D-021): 取り消しは API で消す。押した端末が持つ proof の一致で確かめる
