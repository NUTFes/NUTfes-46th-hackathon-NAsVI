# Sheet

地図の上に、下から出る面を重ねる。

- 使う画面: stamp(V1-f)、layers(V1-h)、building(V1-j・k)、tags(V1-l)
- 見せるもの: なし(中身は画面が入れる)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

中身(children)は自由。CheckRow・StampCongestionPicker・TagCreateField などを入れる。

## 作り

1. つまみ
2. 見出しと補足
3. 閉じる(IconButton)
4. 中身

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| title | 文字列 | ○ | — | | なし |
| subtitle | 文字列 | | なし | | なし |
| onClose | 関数 | ○ | — | | なし |
| children | 部品 | ○ | — | | なし |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 角の丸い面、上に影 | bg-surface、border-subtle、radius.2xl |
| 押下・無効・空・エラー | なし(中身の部品で出す) | |
| 読み込み中 | なし | |

## 使う / 使わない

- 使う: 地図を見たまま、短い操作をするとき
- 使わない: 場所 1 件の情報は PlaceCard(地図の印との位置関係を見せたいので、シートより小さい)

## アクセシビリティ

- 操作方法: 閉じるボタン。下へのスワイプでも閉じる
- 読み上げの文言: 見出しを読み、フォーカスを中に移す
- 押せる大きさ: 閉じるは 44 px

## 未確認・要確認

- 影のトークンが無い(ステップ 3 で足すか、影を使わないか)
