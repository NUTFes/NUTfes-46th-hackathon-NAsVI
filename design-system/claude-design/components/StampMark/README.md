# StampMark

スタンプ(混雑・感想)を地図に示す。拡大すると種類と経過時間。

- 使う画面: map
- 見せるもの: stamps の種類・位置・押した時刻
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

地図の上に置くときは、親を `position: relative` にし、`x`・`y` を渡す。その点が印の中心になる。渡さなければ、文の中に並ぶ。

## 作り

1. 丸(混雑は濃淡と数字、感想はマーク)
2. 札(拡大時: 種類と経過時間)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| kind | 列挙 | ○ | — | congestion-1〜5 / fun / food / good | stamps.kind |
| pressedAt | 時刻 | ○ | — | 経過時間を出す | stamps の押した時刻 |
| zoomed | 真偽 |  | false |  | なし |
| more | 数 |  | 0 | まとめたほかの件数。1 以上なら「+N」を出す | なし(端末でまとめる) |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | congestion-1〜5、congestion-border、feeling、feeling-on、map-ring |
| 古い | 混雑は期限を過ぎたら出さない(OQ-4) | stale |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: スタンプ
- 使わない: —
