# CheckRow

1 つの項目の入・切を選ぶ。

- 使う画面: layers(V1-h)、tags(V1-l)、op_places(O1。場所に付ける運営の種類を、複数選ぶ)
- 見せるもの: 表示する印(端末の設定)、タグ(端末。D-014)、運営の種類(場所に付ける。places.labelIds)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

並べ方: `<div class="nv-list">` の中に並べる。

## 作り

1. アイコン
2. 名前と補足
3. チェック

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| label | 文字列 | ○ | — |  | なし |
| sublabel | 文字列 |  | なし | 「最初からあるタグ」「4 件」 | なし |
| icon | 部品 |  | なし |  | なし |
| checked | 真偽 | ○ | — | 運営の種類(O1)は、その種類の id が場所の labelIds に含まれるか | なし(端末。タグ・表示する印)。運営の種類は places.labelIds |
| onToggle | 関数 | ○ | — | タグは markPlace・unmarkPlace。運営の種類(O1)は assignLabel・unassignLabel | なし(端末。タグ・表示する印)。運営の種類は PUT・DELETE /places/{placeId}/labels/{labelId} |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | text-primary、text-secondary |
| 選択中 | チェックの面を lilac | action-primary、action-on-primary |
| 押下 |  | state-pressed |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: いくつかの項目を、それぞれ入・切するとき。運営が場所に種類を付けるときも、種類ごとに 1 行にして、複数を選べるようにする(O1。FormField のラベルの下に並べる)
- 使わない: 1 つを選ぶだけなら Chip

## アクセシビリティ

- 操作方法: 行のどこを押しても切り替わる
- 読み上げの文言: role="checkbox"、aria-checked
- 押せる大きさ: 行の高さ 54 px
- 色だけに頼っていないか: チェックの印で分かる
