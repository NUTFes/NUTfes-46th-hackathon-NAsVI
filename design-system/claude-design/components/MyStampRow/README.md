# MyStampRow

自分が押したスタンプを 1 件ずつ並べ、取り消せるようにする。

- 使う画面: stamp(V1-f)
- 見せるもの: Stamp(種類、押した時刻、消えるまでの時間)。自分のスタンプを見分ける方法は OQ-12
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 種類の札(Badge。混雑は濃淡の色、感想はピンク)
2. 時間: 「たった今・30 分で消えます」「12 分前」
3. 取り消す(Button、副)
4. 一覧の下: 「ほか N 件を見る」(新しい順に 3 件より多いとき)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| stampId | 文字列 | ○ | — | 取り消すときに使う | stamps.id |
| kind | 列挙 | ○ | — | congestion-1〜5 / fun / food / good | stamps.kind |
| pressedAt | 時刻 | ○ | — | 経過時間を出す | stamps の押した時刻 |
| expiresAt | 時刻 | | なし | 混雑だけ。期限は OQ-4 | なし(端末で計算。期限が決まれば API でもよい) |
| onRetract | 関数 | ○ | — | retractStamp | なし(取り消しを API に載せるかは OQ-12) |

Design System で足した props: retracting(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 枠つきの行 | border-subtle、text-secondary、congestion-1〜5、feeling |
| 取り消し中 | 行を薄くし、取り消すを押せなくする | opacity.disabled |
| 期限切れ | 一覧から消す | |
| その他(押下・空・エラー) | 押下は中の Button。0 件なら欄ごと出さない。失敗は Toast | |

## 使う / 使わない

- 使う: スタンプのシートの「自分が押したスタンプ」。新しい順に 3 件まで(apply-log ⑥、2026-11-22 に決定)
- 使わない: 他の人のスタンプは StampMark(地図)

## アクセシビリティ

- 操作方法: 取り消すをタップ
- 読み上げの文言: 「混雑3、たった今、30 分で消えます、取り消す」
- 押せる大きさ: 取り消すは 32 px(行の高さで 44 px を確保)
- 色だけに頼っていないか: 種類は札の文字で分かる

## 未確認・要確認
