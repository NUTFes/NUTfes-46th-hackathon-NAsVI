# TagCreateField

自作のタグの名前を入れて作り、開いている場所に付ける。

- 使う画面: tags(V1-l)
- 見せるもの: なし(端末。D-014)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 見出し
2. 入力
3. 作る
4. 補足: 作ると開いている場所に付くこと、**タグは端末の中にだけ保存され、データを消すと消えること**(D-014。枠ではなく補足の文で出す。2026-11-22 に決定)、名前の決まりは OQ-13

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| value | 文字列 | ○ | '' |  | なし |
| onCreate | 関数 | ○ | — | defineMyTag と markPlace | なし(端末) |
| error | 文字列 |  | なし | 空欄・重複など(OQ-13) | なし |

Design System で足した props: onChange(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | bg-page、border-control |
| エラー | 入力の下に赤い文 | danger-text |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: タグのシートの中
- 使わない: —

## アクセシビリティ

- 操作方法: 文字入力と作る
- 読み上げの文言: 「新しいタグの名前」
- 押せる大きさ: 高さ 44 px
- 色だけに頼っていないか: エラーは文で
