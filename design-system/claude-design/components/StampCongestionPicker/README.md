# StampCongestionPicker

混雑 1〜5 のどれかを押して、足元にスタンプを押す。

- 使う画面: stamp(V1-f)
- 見せるもの: stamps の種類(混雑 1〜5)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 5 つのボタン(濃淡と数字)
2. 両端の説明(空いている・とても混んでいる)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| disabled | 真偽 |  | false | 現在地が無いとき | なし |
| onPick | 関数 | ○ | — | pressStamp | stamps(POST) |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | congestion-1〜5、congestion-1〜5-on、congestion-border |
| 無効 | 薄くし、位置の許可を案内 | opacity.disabled |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: スタンプのシートの中
- 使わない: —

## アクセシビリティ

- 操作方法: 1 回押すと送る(F3: 2 操作)
- 読み上げの文言: 「混雑3」「混雑5 とても混んでいる」
- 押せる大きさ: 1 つ 60×52 px
- 色だけに頼っていないか: 数字で分かる
