# DestinationBar

カメラの上に、行き先と距離を示す。

- 使う画面: camera(V3-a)
- 見せるもの: Destination、places の名前
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 方角の矢印
2. 「〇〇まで N m」
3. やめる

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| placeName | 文字列 | ○ | — | 1 行。入りきらないときは末尾を「…」にする(apply-log ⑤) | places.name |
| remainingM | 数 | ○ | — |  | なし(端末で計算) |
| onStop | 関数 | ○ | — | Destination.clear ※ | なし |

Design System で足した props: headingDeg(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 黄の帯 | destination、destination-on |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: カメラの画面で案内中
- 使わない: 地図の下では DestinationCard

## アクセシビリティ

- 操作方法: やめるをタップ
- 読み上げの文言: 「お化け屋敷まで 150 メートル」
- 押せる大きさ: やめるは 40 px(44 px にする)
- 色だけに頼っていないか: 文で分かる
