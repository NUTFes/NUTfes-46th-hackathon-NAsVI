# BuildingShapePreview

運営が、建物の形(OpenStreetMap)を確かめ、読み込み直す。

- 使う画面: op_landmarks
- 見せるもの: landmarks の輪郭(footprint。D-018)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 形の図
2. 読み込み直す
3. 出典(© OpenStreetMap contributors)

| onReload | 関数 | ○ | — |  | なし |
