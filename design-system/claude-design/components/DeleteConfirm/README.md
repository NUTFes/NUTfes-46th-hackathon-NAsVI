# DeleteConfirm

運営が、消す前に連動して起きることを見て決める。

- 使う画面: op_places、op_landmarks
- 見せるもの: places / landmarks
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 見出し(何を消すか)
2. 連動して起きること
3. 削除する・やめる

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| title | 文字列 | ○ | — |  | なし |
| effects | 文字列 | ○ | — | 場所を消すとき「検索・一覧から消え、案内も終わる」。建物を消すとき「階ごとの見取り図も消えます」を含める(API で連動して消える。下の未確認・要確認) | なし |
| onConfirm・onCancel | 関数 | ○ | — | removePlace / removeLandmark | DELETE |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 赤い枠 | danger、danger-bg |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 削除の前(戻せない操作)
- 使わない: —

## アクセシビリティ

- 操作方法: キーボード。最初のフォーカスは「やめる」
- 読み上げの文言: role="alertdialog"
- 押せる大きさ: 40 px
- 色だけに頼っていないか: 文で分かる

## 未確認・要確認

- 解消(API 設計の決定): 建物を削除したときは、その建物の階ごとの見取り図も一緒に消える(API-29。場所が付いている建物の削除を断る規則 API-27 は変わらない)。建物を消す確認では、effects に「階ごとの見取り図も消えます」を含める。#21 の台帳 API-29 で確定(2026-11-23)
