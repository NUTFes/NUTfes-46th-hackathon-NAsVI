# FacilityMark

設備(案内所・トイレ・休憩所・ゴミ箱)の位置を示す。

- 使う画面: map、building
- 見せるもの: places(kind が案内所・トイレ・休憩所・ゴミ箱。D-017)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

地図の上に置くときは、親を `position: relative` にし、`x`・`y` を渡す。その点が印の中心になる。渡さなければ、文の中に並ぶ。

## 作り

1. 白い丸
2. 種類のアイコン(トイレは塗りつぶしの男女、案内所は丸で囲んだ i)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| kind | 列挙 | ○ | — | info / wc / rest / trash | places.kind(info・wc・rest・trash。API と同じコード。#21 の API-36) |
| zoomed | 真偽 |  | false |  | なし |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 白い丸と濃いアイコン | facility、facility-on、map-ring |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 設備
- 使わない: —

## アクセシビリティ

- 操作方法: なし(押すかは未定)
- 読み上げの文言: 「トイレ」
- 押せる大きさ: —
- 色だけに頼っていないか: アイコンの形で区別し、色は増やさない
