# SearchField

名前の一部で場所を探す。

- 使う画面: map、search
- 見せるもの: Search(検索語)。結果は places
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 虫めがね
2. 入力
3. 消す
4. 文章で探す(拡張。OQ-8)

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| value | 文字列 | ○ | '' |  | search の keyword |
| placeholder | 文字列 |  | 企画・場所を検索 |  | なし |
| onChange・onClear | 関数 | ○ | — |  | なし |
| naturalSearch | 真偽 |  | false | 拡張の「文章で探す」を出すか(OQ-8) | searchNatural |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | bg-surface、border-control |
| 入力中 | 枠を lilac | action-primary |
| 読み込み中 | なし(目安 1 秒以内。結果が出るまで前の結果を残す) |  |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 場所を名前で探すとき
- 使わない: 種類で選ぶときは Chip

## アクセシビリティ

- 操作方法: 文字入力
- 読み上げの文言: 「企画・場所を検索」
- 押せる大きさ: 高さ 48 px
- 色だけに頼っていないか: 入力中は枠の太さも変える
