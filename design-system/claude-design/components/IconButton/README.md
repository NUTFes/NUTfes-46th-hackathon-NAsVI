# IconButton

アイコンだけで操作を 1 つ実行する(閉じる、拡大・縮小、現在地へ、表示)。

- 使う画面: map、card、stamp、layers、building、tags、guide
- 見せるもの: なし
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

## 作り

1. 面: 丸めた四角
2. アイコン

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| icon | アイコン名 | ○ | — | close / zoom-in / zoom-out / locate / layers | なし |
| label | 文字列 | ○ | — | 読み上げ用の名前(「閉じる」) | なし |
| disabled | 真偽 |  | false | 縮小の限界、現在地が使えないとき | なし |
| onPress | 関数 | ○ | — |  | なし |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 | 枠つきの面 | bg-surface、border-subtle、text-primary |
| 押下 | 面に色を重ねる | state-pressed |
| 無効 | 薄くする。理由を label に足す(「これ以上は縮小できません」) | opacity.disabled、text-disabled |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 文字が無くても意味が通じる操作
- 使わない: 意味が通じにくい操作は Button(文字つき)

## アクセシビリティ

- 操作方法: タップ
- 読み上げの文言: label を読む
- 押せる大きさ: 44 px
- 色だけに頼っていないか: アイコンの形で分かる
