# ParkingMark

駐車場の位置を示す。

- 使う画面: map
- 見せるもの: places(kind=parking)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

地図の上に置くときは、親を `position: relative` にし、`x`・`y` を渡す。その点が印の中心になる。渡さなければ、文の中に並ぶ。

## 作り

1. 青い四角
2. P

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| placeId | 文字列 | ○ | — |  | places.id |

## 状態

| 状態 | 見た目・振る舞い | 使うトークン |
|---|---|---|
| 通常 |  | parking、parking-on |
| その他(押下・無効・読み込み中・空・エラーのうち上に無いもの) | なし(この部品では起きない、または中の部品で出す) | |

## 使う / 使わない

- 使う: 駐車場
- 使わない: —

## アクセシビリティ

- 操作方法: タップでカード
- 読み上げの文言: 「駐車場」
- 押せる大きさ: 周りを 44 px
- 色だけに頼っていないか: P の文字
