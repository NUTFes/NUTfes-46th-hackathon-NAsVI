# DestinationMark

行き先と、現在地からの直線を示す。

- 使う画面: map、guide
- 見せるもの: places(行き先の位置)
- 状態: 下書き(チームで確認する前)。※ の付いた所は、概念設計の変更待ち

地図の上に置くときは、親を `position: relative` にし、`x`・`y` を渡す。その点が印の中心になる。渡さなければ、文の中に並ぶ。

## 作り

1. 黄の印(ライトは濃い縁)
2. 直線の点線

## 渡すもの(props)

| 名前 | 型 | 必須 | 既定値 | 取りうる値 / 説明 | API の項目 |
|---|---|---|---|---|---|
| placeId | 文字列 | ○ | — |  | places.id |
| showLine | 真偽 |  | true |  | なし |

Design System で足した props: name・lineLength・lineAngleDeg(仕様には無い。`components/index.d.ts` に【Design System で追加】と書いた)
